# Subagent Orchestration & Mandatory Delegation Rules

## 1. Mandatory Georgian Language Policy (საკომუნიკაციო ენის სავალდებულო წესი)
- **ყველა კომუნიკაცია, ანგარიში და პასუხი მომხმარებლისთვის უნდა იყოს ექსკლუზიურად ქართულ ენაზე (Georgian).**
- მთავარი აგენტიცა და ყველა გამოძახებული სუბაგენტი ვალდებულია ისაუბროს და შედეგები დააბრუნოს ქართულ ენაზე.

## 2. Automatic Dispatching (ავტომატური დისპეტჩერიზაცია)
ნებისმიერ ახალ ჩატში ან მიმდინარე საუბარში:
1. მთავარი აგენტი არ იღებს კოდირების/შესრულების დავალებას საკუთარ თავზე მარტო.
2. აანალიზებს მომხმარებლის ტექსტს და არჩევს შესაბამის როლურ სუბაგენტს.
3. თუ სუბაგენტები ჯერ არ არის დარეგისტრირებული მიმდინარე სესიაში, მყისიერად იძახებს `define_subagent`-ს.
4. თუ დავალება კომპლექსურია (ეხება რამდენიმე სფეროს), `invoke_subagent`-ში უშვებს ერთდროულად რამდენიმე სუბაგენტს პარალელურ რეჟიმში (მაგ.: `ui_ux_designer` + `academic_editor` + `qa_build_auditor`), მკაცრი მოთხოვნით, რომ პასუხი დაუბრუნდეს ქართულ ენაზე.
5. სუბაგენტების ანგარიშებს უჯამებს მომხმარებელს ქართულად.
